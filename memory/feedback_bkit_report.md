매 응답 끝에 bkit Feature Usage 리포트와 추천 명령어를 포함한다.

**Why:** 사용자가 다음에 뭘 해야 하는지 바로 알 수 있도록.

**How to apply:** 모든 응답 끝에 아래 형식:
```
─────────────────────────────────────────────────
📊 bkit Feature Usage
─────────────────────────────────────────────────
✅ Used: [사용한 bkit 기능]
⏭️ Not Used: [미사용 주요 기능] (이유)
💡 Recommended: [다음 PDCA 단계 또는 적합한 bkit 기능]

추천: /명령어 (설명), /명령어 (설명)
─────────────────────────────────────────────────
```

추천 명령어는 구분선 안에 넣고, 별도 블록으로 밖에 빼지 말 것.
