# 버그헌트 (한글 명령어) - bug-hunt alias

이 명령어는 `/bug-hunt`의 한글 alias입니다. 동작은 완전히 동일합니다.

인자: $ARGUMENTS

---

## 동작

`skills/bug-hunt.md`의 모든 로직을 그대로 실행합니다 — Codex 정적 버그헌트(백그라운드) + 라이브 헬스/invariant 스윕 + 발견 항목 라이브 교차검증(확정/반박) + 우선순위 보고 + (승인 시)수정·재검증·배포.

**즉시 `bug-hunt.md`의 절차를 처음부터 끝까지 따라 실행하세요.**

핵심: 🤝Codex협업 · 🔬실행증거 필수 · 🛡️운영데이터 보호(더미+cleanup) · ⚖️의도된 정책은 버그 아님.

## 사용 예시
```bash
/버그헌트                          # 활성 프로젝트 전체 숨은 버그 헌트 (보고만)
/버그헌트 견적서 재고 매출          # 특정 도메인 집중
/버그헌트 전체 --fix               # 발견 + 승인 후 수정
/버그헌트 auto-shop-manager --fix --deploy   # 수정 + 재검증 + 배포
```

전체 명세는 [bug-hunt.md](bug-hunt.md) 참조.
