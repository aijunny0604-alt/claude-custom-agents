# /네이버키워드 — 네이버 파워링크·SEO 키워드 추출 에이전트 (v1.0)

## 목적
네이버 **검색광고 키워드도구 API**(무료)로 **실제 검색량·경쟁도·파워링크 노출수**를 받아, 블로그 제목 SEO와 파워링크 광고에 쓸 키워드를 데이터 기반으로 뽑는다. (추정 아님, 실데이터)

## 준비 (이미 완료)
- API 키: `~/.secrets/naver_searchad.json` (API_KEY, SECRET_KEY, CUSTOMER_ID) — git 저장소 바깥, 커밋 금지.
- 헬퍼: `C:\Users\MOVEAM_PC\claude-custom-agents\scripts\naver_keywords.py`

## 절차
### 1. 시드 키워드 정하기
- 인자로 받은 차종·작업에서 **시드 키워드 2~5개**를 만든다. 공백은 자동 제거된다.
  - 예: 입력 "아반떼CN7 워커 인증배기" → 시드 `아반떼배기` `인증배기` `가변배기` `머플러튜닝`.
  - 차종 일반명 + 작업 통용어 위주(브랜드/코드 조합도 1~2개). 너무 롱테일만 넣으면 결과가 적다.

### 2. API 조회 (실행)
```powershell
python "C:\Users\MOVEAM_PC\claude-custom-agents\scripts\naver_keywords.py" "시드1" "시드2" "시드3"
```
- 결과가 `C:/tmp/naver_kw_result.json` (UTF-8)에 저장된다. **이 파일을 Read**해서 분석한다. (콘솔 출력은 한글이 깨질 수 있으니 파일을 읽을 것)
- JSON 구조: `{hints, count, keywords:[{kw, pc(월PC검색), mo(월모바일검색), total(합계), comp(경쟁: 낮음/중간/높음), pl(파워링크 평균노출광고수)}...]}` — 검색량 합계 내림차순 정렬돼 있음.

### 3. 분석·필터
- 시드와 **작업/차종 관련 없는 키워드는 제외**(엉뚱한 연관어 섞임). 사람이 판단.
- 지표 해석:
  - `total`(월 검색량 합계): 노출 기회. 높을수록 유입 크지만 경쟁도 큼.
  - `comp`(경쟁정도): 낮음=파워링크 입찰 저렴·상위 쉬움, 높음=비쌈. **낮음~중간 + 검색량 있는** 키워드가 파워링크 가성비.
  - `pl`(파워링크 평균노출광고수): 그 키워드에 붙은 광고 수. 낮으면 경쟁광고 적음.

### 4. 산출 (2가지)
1. **블로그 SEO 제목 키워드**: 검색량 상위 + 작업과 직접 관련 키워드 3~6개를 골라, 팀퍼비드/무브 제목 규칙(`{메이커 코드 모델} 작업명`)에 자연스럽게 녹인 **제목 후보 2~3개** 제안.
2. **파워링크 광고 키워드**: `검색량 있음 + 경쟁 낮음~중간 + pl 낮음` 우선으로 **입찰 후보 키워드 10~15개**를 표로. 컬럼: `키워드 | 월검색(PC/모바일/합계) | 경쟁 | PL노출 | 추천도`.
- 표는 마크다운. 근거(검색량·경쟁) 명시. 🚨 데이터에 없는 수치 지어내지 말 것.

### 5. 마무리
- 조회한 시드·연관키워드 수, 채택/제외 기준을 1~2줄 요약.
- (선택) 블로그 작성과 연계 시: 뽑은 제목 키워드를 `/팀퍼비드블로그`·`/무브모터스블로그` 제목에 반영하도록 안내.

## 금지 사항
- API 키를 스킬/커밋/응답에 노출하지 말 것 (항상 `~/.secrets`에서만 읽음).
- 검색량·경쟁·입찰 수치를 추정으로 지어내지 말 것 (API 결과만 사용, 없으면 "데이터 없음").
- 연관키워드 중 명백히 무관한 것(다른 업종·오타)은 제외.

## 참고
- 키워드도구는 연관키워드+검색량+경쟁+PL노출까지 준다. 정확한 **예상 입찰가/클릭수**가 더 필요하면 검색광고 '예상 실적' API(별도 엔드포인트) 확장 가능.
