# /하이라이트 — 단일 영상 자동 하이라이트 브이로그 편집 (한글 명령어)

`/vlog-highlight`의 한글 alias. **모든 동작과 절차는 `vlog-highlight.md`와 100% 동일**.

호출 시 즉시 `vlog-highlight.md`의 절차를 따라 실행한다:

1. 사전 점검 (파일 존재, ffmpeg, faster-whisper)
2. 오디오 추출 (16kHz mono WAV)
3. STT 실행 (`scripts/video_stt.py` 헬퍼)
4. 트랜스크립트 분석 → 하이라이트 후보 자동 마킹
5. B-roll 후보 자동 식별 (`scripts/broll_detect.py` + 프레임 미리보기)
6. AskUserQuestion 4문항 (길이·비율·관점·B-roll 비중)
7. 컷 구성안 자동 생성 + 사용자 컨펌
8. 컷 일괄 렌더링 (1920×1080 또는 1080×1920)
9. concat 합본
10. 검증 (길이·해상도·오디오)
11. 결과 보고 + 후속 제안

## 절대 원칙

- **원본 오디오 보존** (`anullsrc` 무음 강제 금지)
- **대화만 잘라 붙이지 마라** (B-roll 25% 이상 필수)
- **시간순 유지** (브이로그는 스토리)
- **컷 경계는 STT 세그먼트 기준** (문장 중간 자르지 마)
- **B-roll 후보는 시각 확인 후 채택** (검은 화면/흔들림 제외)

## /auto-vlog와 차이

| 시나리오 | 사용 스킬 |
|---------|----------|
| 여러 짧은 클립 폴더 → 합치기 | `/auto-vlog` (또는 `/브이로그`) |
| 단일 긴 영상 (30분+) → 하이라이트만 뽑기 | **`/vlog-highlight` (또는 `/하이라이트`)** |
