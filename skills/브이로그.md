# /브이로그 — 자동 영상 편집 에이전트 (한글 명령어)

`/auto-vlog`의 한글 alias. **모든 동작과 절차는 `auto-vlog.md`와 100% 동일**.

호출 시 즉시 `auto-vlog.md`의 절차를 따라 실행한다:

1. 폴더 스캔 + 메타데이터 수집
2. 썸네일 추출 + 시각 분석
3. AskUserQuestion 4문항 (비율·길이·옵션·중복처리)
4. 컷 구성안 자동 생성 + 사용자 컨펌
5. 자막 텍스트 파일 작성 (UTF-8)
6. 컷 정규화 렌더링 (**원본 오디오 보존**)
7. concat 합본
8. 검증 (길이·해상도·오디오 트랙)
9. 결과 보고 + 후속 옵션

## 절대 원칙

- **원본 오디오 보존** (`anullsrc` 강제 입히기 금지)
- **자막은 UTF-8 .txt 파일 + drawtext `textfile=`**
- **Windows 경로 escape** (`C\:/path/file.txt`)
- **concat 호환 통일 사양** (1080×1920, h264, aac 44100 stereo)
- **검증 필수** (ffprobe로 길이·해상도·오디오 stream 확인)

## 출력 직후 필수

사용자 전역 CLAUDE.md 규칙대로 응답 말미에 bkit Feature Usage 블록 + 추천 명령어 줄 포함.
