# /검색광고점검 — 네이버 검색광고 계정 진단·최적화 에이전트 (v1.0)

## 목적
네이버 검색광고 관리 API로 계정을 **읽어서 진단**하고 **최적화안**을 제시한다. 🚨 쓰기(입찰·키워드·소재·on/off 변경)는 **실제 광고비·노출에 영향**이라 **반드시 사용자 승인 후에만** 실행한다.

## 준비 (완료)
- 키: `~/.secrets/naver_searchad.json` (repo 바깥, 커밋금지). CUSTOMER_ID=1541160 (무브모터스).
- 헬퍼: `scripts/naver_ad_audit.py` (읽기 감사), `scripts/naver_keywords.py` (연관키워드).

## 절차
### 1. 읽기 감사 (구조)
```powershell
python "C:\Users\MOVEAM_PC\claude-custom-agents\scripts\naver_ad_audit.py"
```
→ `C:/tmp/naver_ad_audit.json` (캠페인→광고그룹→키워드(입찰가)→소재). **이 파일을 Read**해서 분석(키워드 5천개 규모라 전량 나열 말고 그룹별 요약).

### 2. (선택) 성과 조회 — "stats" 인자 시
- 각 광고그룹/키워드의 `GET /stats?id=<id>&fields=["impCnt","clkCnt","salesAmt","ctr","cpc","avgRnk","ccnt"]&timeRange={"since":"YYYY-MM-DD","until":"YYYY-MM-DD"}` (최근 7~30일). 서명은 uri=`/stats`.
- 노출/클릭/비용/전환으로 **저성과(비용>0·전환0), 고효율(전환 좋은데 노출 낮음), 낭비 키워드**를 가려낸다.

### 3. 진단 항목
- **구조**: 중복 캠페인/그룹(같은 키워드 세트 중복), 그룹당 키워드 과다(>800 품질저하), 소재 1개 그룹(A/B 불가), 상태(일시중지) 점검.
- **입찰**: 개별입찰 편차, 고입찰 키워드가 성과 대비 적정한지, 그룹입찰 vs 개별입찰.
- **소재**: 그룹당 2개 이상, 제목·설명에 핵심 키워드/차별점.
- **예산**: 캠페인 일예산 배분이 성과와 맞는지.

### 4. 최적화안 제시 (승인 전, 실행 금지)
- "이 키워드 입찰 X→Y", "저성과 키워드 N개 제외", "이 그룹에 소재 추가", "중복 캠페인 통합", "예산 재배분" 등 **구체안 + 근거(데이터)**를 표로. 예상 효과·리스크 명시.

### 5. 적용 (오직 "apply" + 명시적 승인 시)
- 승인된 항목만 API로 반영: `PUT /ncc/keywords/{id}`(입찰 bidAmt), `PUT /ncc/adgroups/{id}`, `POST/DELETE /ncc/keywords`(추가/제외), on/off 등.
- 🚨 반영 전 "무엇을 어떻게 바꿀지" 최종 확인 1회. 반영 후 변경내역 보고.

## 금지 사항
- 사용자 승인 없이 쓰기(입찰·키워드·소재·예산·on/off) 절대 금지. 기본은 읽기·제안만.
- API 키를 응답·커밋에 노출 금지.
- 성과·수치를 추정으로 지어내지 말 것(API 결과만).
