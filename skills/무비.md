# /무비 — 무브모터스 무비 쇼츠 제작 에이전트 (v1.0)

블로그 작업기 또는 키컷 이미지 폴더만 주면, **무비(Moobie) 시리즈 공식 포맷**으로
Seedance 프롬프트 + 나레이션 대본 + 업로드 패키지를 한 번에 만들어주는 에이전트.

> 영상 생성 자체는 Higgsfield Seedance 2.0(외부 툴)에서 실행하고, 편집은 CapCut에서 한다.
> 이 에이전트는 **그 앞단(기획·프롬프트·대본·업로드문안)을 100% 자동화**한다.

## 🎙️ 일본어 음성 차단 블록 (모든 씬 프롬프트 끝에 필수)
```

language (NO Japanese, NO Korean, NO English). NO music, NO BGM.
ONLY: [환경음]. NO subtitles, NO text.
```
+ Higgsfield 설정에서 **Generate Audio = OFF** 안내. 환경음 예: workshop ambience, welding arc buzz, wrench clicks, engine rumble, exhaust pops.

## 실행 절차 (순서대로)

### 0. 사전 점검 + EP 셋업
- `$ARGUMENTS`가 비었으면 블로그 URL 또는 이미지 폴더 경로를 1회 묻는다.
- **AskUserQuestion으로 EP 정보 수집**: EP번호 / 차종 / 제품·작업 / 색상 / 씬개수(6~8) / 총길이.

### 1. 소스 수집
- **블로그 URL이면**: 네이버는 일반 fetch 차단 → Playwright로 `PostView.naver?blogId=…&logNo=…` 렌더링해 본문 텍스트 + 작업사진 URL 추출. 사진은 `User-Agent` + `?type=w966` 헤더로 다운로드(핫링크 우회).
- **폴더면**: 이미지 번호순 정렬.

### 2. 키컷 선정 (전부 X, 주요 씬만)
- 이미지를 ffmpeg xstack 컨택트시트로 모아 시각 확인.
- 8씬 구조에 매핑되는 핵심 컷만 선정(보통 6~8장). 컷 추가/제외는 사용자 컨펌.

### 3. 8씬 구조 배정
| 씬 | 길이 | 내용 |
|---|---|---|
| 1 | 8s | 입고 + 무비 인사 |
| 2 | 8s | 작업 소개 (씬1과 다른 구도) |
| 3 | 15s | 언박싱 + 용접 (용접맨 시트, 레인보우 비드) |
| 4 | 15s | 핵심 작업 (밸브/장착, First/Last Frame) |
| 5 | 15s | 부품 장착 |
| 6 | 15s | 시동 + 퍼포먼스 (배기 화염) |
| 7 | 15s | 스마트폰 인증(#00FF00 그린스크린) + 엔딩 |
> 길이에 따라 6~8씬 조절. 구도는 매 씬 다르게.

### 4. Seedance 2.0 한글 멀티샷 프롬프트 생성 (씬별)
- **반드시 ≤3000자**, 한글. 구조: `세로 9:16. [씬 요약] - [길이]초.` → 설정 → (변화씬)시작/종료 상태 → 애니메이션 타임라인([0-X초]…) → 치비 무비 묘사 → 카메라(매 씬 다르게) → `한국 웹툰 치비 스타일, 셀 셰이딩, 부드러운 60fps, 9:16` → **AUDIO 차단블록** → `@dc42431d-bee7-42d4-bd26-852f693aecaf`
- 변화씬(밸브 OPEN↔CLOSED, 부품 장착, 범퍼 탈거)은 **First/Last Frame** 사용 명시. 가변밸브는 `flap tilts open and close, NOT spinning`, SF/LED 금지.
- 차량 일관성: `ALREADY RAISED`(리프트에 이미 떠있는 상태로 시작).

### 5. 클로바 다인 나레이션 대본 (씬별)
- 보이스 다인(밝고 친근 20대 여성), 외부 더빙 → CapCut 합성.
- 톤: 오프닝 밝게(1.0x) / 작업 0.95x / 시동·완성 신나게(1.05x) / 엔딩 따뜻하게.
- 필수 멘트: 오프닝 `"안녕하세요! 무브모터스의 무비예요! 💕"` / 인증 `"이 영상, 실제 작업 사진으로 만든 거예요!"` / 엔딩 `"문의는 010-5858-6046으로! 무브모터스에서 만나요~!"`

### 6. 업로드 패키지 생성
- 제목: `EP[N] - 귀염뽀짝 무비의 [차종] [작업명] 튜닝 #무브모터스`
- 설명글(복붙 템플릿 채움) + 해시태그(고정 `#무브모터스 #무비 #MoveMotors #부산튜닝샵 #shorts #쇼츠` + 차종/제품별) + 고정댓글(연락처 010-5858-6046, blog.naver.com/move_am, insta @move_automotive, 유튜브 @IMOVEAutomotive).
- 썸네일 가이드: 세로 9:16, 상단 BEFORE / 하단 AFTER / 무비+화살표 / "변신!" 빨강.

### 7. CapCut 합성 안내
- 세로 1080×1920 60fps. Track1 영상 / Track2 다인 나레이션(씬 0.3초 후) / Track3 BGM 20% / Track4 SFX(용접·배기·화염).
- 그린스크린(#00FF00) 크로마키 → 실제 작업사진 슬라이드 + 연락처 오버레이. 자막 나눔스퀘어 Round Bold 80-100px.

### 8. 산출물 저장
- `docs/무비_EP[N]_[차종].md`에 씬별 프롬프트 + 나레이션 + 업로드문안 전부 저장.

## 절대 원칙
1. Seedance 프롬프트 **≤3000자**
2. "심플한 게 최고" — 검증된 공식만, SF요소 X
3. 일본 스튜디오명 금지, 치비 2-3등신 명시 (일본어 음성 차단)

7. Generate Audio 항상 OFF
