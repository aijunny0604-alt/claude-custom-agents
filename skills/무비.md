# /무비 — 무브모터스 무비 쇼츠 제작 에이전트 (v2.0)

블로그 작업기 또는 키컷 이미지 폴더만 주면, **EP.1/EP.2로 검증된 무비 공식 포맷**으로
Seedance 프롬프트 + 나레이션 + 업로드 패키지를 한 번에 만든다.

> 정본 레퍼런스: `refs/moobie/master_template_v2.0.md` + `refs/moobie/EP2_example.md` (반드시 이 양식 준수)
> 영상 생성은 Higgsfield Seedance 2.0, 편집은 CapCut. 이 에이전트는 그 앞단을 자동화한다.

## ⛔ v2.0 핵심 규칙 (절대 준수 — 과거 실수 방지)
1. **프롬프트는 영어**, 길이 **800~1000자(최적 900~980)**. (한글/3000자 아님!)
2. **씬당 8초 × 6씬 = 48초**. (15초 멀티샷 아님!)
3. **모든 씬에 치비 무비(Moobie) 등장** — 단순 사진 변환 아님. 무비가 작업을 진행/리액션.
4. **치비 2-3등신 고정** + Korean webtoon. 일본 스튜디오명 금지(일본어 음성 유발).
5. 프롬프트 끝에 **AUDIO 공식 + 레퍼런스 ID** 필수. Seedance Generate Audio = OFF.

## 🏆 황금 공식 (프롬프트에 그대로)
입 움직임: `Natural expressive facial animation: mouth moves with [감정], animated emotion. Not specific lip sync, just natural animated expression.`
감정 키워드: 인사=smiling excited greeting / 설명=thoughtful explaining / 놀람=amazed star-eyed excitement / 작업=focused concentration / 성공=joyful amazed cheering with star eyes / 엔딩=warm farewell
AUDIO 공식: `AUDIO: [환경음]. NO dialogue, NO voices, NO music.` + 빈 줄 + `NO subtitles, NO text.`
스타일: 옵션A 기본웹툰 / B 큐티(pastel+sparkles) / C 시네마틱리얼 / **D 하이브리드(큐티1-4+리얼5-6, 추천)**. 큐티강도 은은→기본→폭발(클라이맥스 1~2회만).

## 실행 절차
### 0. EP 셋업
- `$ARGUMENTS` 비면 블로그 URL/폴더 경로 1회 요청.
- AskUserQuestion: EP번호 / 차종 / 제품·작업 / 색상 / 포맷(세로9:16 기본) / 씬수(6 기본).

### 1. 소스 수집
- 블로그 URL → Playwright `PostView.naver?blogId=…&logNo=…` 렌더링 → 본문+작업사진 추출, 사진은 `User-Agent`+`?type=w966`로 다운로드(핫링크 우회).
- 폴더 → 번호순. ffmpeg xstack 컨택트시트로 시각 확인.

### 2. 키컷 선정 + 6씬 매핑 + 슬롯 지정 (사용자 컨펌)
표준 6씬: 1 입고+무비 인사 / 2 탈거(First/Last) / 3 제품 언박싱🎁 / 4 핵심 장착(매직/밸브) / 5 출차·전환(큐티→리얼) / 6 밖에서 완성 감탄 엔딩. 작업 성격 따라 가감.
**레퍼런스 슬롯 규칙 (필수)**: **Slot 1 = 무비 캐릭터 시트(`@dc42431d-bee7-42d4-bd26-852f693aecaf`) 항상 고정** / Slot 2~ = 해당 씬 키컷 이미지(순서대로). 모든 컷에 무비 시트가 Slot 1로 들어가야 함 → 매 씬 무비 등장·일관성 보장. 각 컷마다 "레퍼런스 → Slot 1: 무비시트 / Slot 2: N.jpeg" 명시.

### 3. Seedance 2.0 영어 프롬프트 생성 (씬별, 900~980자)
구조: `Vertical 9:16 composition. [스타일].` → Setting(배경/분위기) → (변화씬)Starting/Ending → Animation(무비 동작 + 치비 풀스펙) → 입움직임 공식 → Character fully integrated(조명) → Camera(씬마다 다르게) → 스타일줄 → `8 seconds, 60fps, 9:16 vertical.` → AUDIO 공식 → `@dc42431d-...`
- 변화씬(탈거/장착/밸브)=First/Last Frame, 가변밸브 `flap tilts open and close, NOT spinning`, SF/LED 금지.
- 엘리멘트(반복 제품)=`@element_name` + 핵심특징 텍스트 병기.
- 연출 옵션: 분할구도/플래시프레임/치비변형/스피드라인/언박싱 — 적절히.
- `refs/moobie/EP2_example.md`의 6씬을 톤·길이 레퍼런스로 사용.

### 4. 클로바 다인 나레이션 (씬별, 총 ~39초)
다인(밝고 친근 20대 여성). 톤: 오프닝 밝게1.0x/작업0.95x/성공1.05x/엔딩따뜻0.95x. 오프닝 `"안녕하세요! 무브모터스의 무비예요! 💕"`, 엔딩 `"…무브모터스로 오세요~!"`.

### 5. 업로드 패키지
제목 `EP[N] - 귀염뽀짝 무비의 [차종] [작업명] ✨ #무브모터스`(롱폼) / `[차종] [작업] 48초 변신! 🔥 #shorts`. 설명글(인사/작업포인트/효과/매장/링크) + 해시태그(고정 `#무브모터스 #무비 #MoveMotors #부산튜닝샵 #shorts` + 차종/제품별) + 고정댓글(010-5858-6046 등). 썸네일 BEFORE/AFTER+무비+큰텍스트.

### 6. Seedance 설정 + CapCut 안내
Seedance 2.0 Pro / 9:16 1080×1920 / 60fps / Motion 7-9 / 8s / **Generate Audio OFF** / Slot1 무비시트 / 시드 씬1 기록 후 통일. 생성순서 추천 씬3→4→6→5→1→2.
CapCut 1080×1920 60fps, Track1 영상/Track2 다인(0.3초후)/Track3 BGM20%/Track4 SFX. 씬4→5 0.5초 화이트플래시 전환. 자막 나눔스퀘어 Round Bold 80-100px.

### 7. 산출물 저장 (★입력 이미지 폴더에 저장)
**반드시 입력으로 받은 이미지/소스 폴더 안에** `무비_EP[N]_[차종].md`로 저장. (예: 입력이 `D:\느시`면 → `D:\느시\무비_이보크_JSR.md`). docs 폴더 아님!
씬별 프롬프트 + 컷별 슬롯 지정(Slot 1/2…) + 나레이션 + 자막 + 업로드문안 전부 포함.
블로그 URL이 입력이면 다운로드한 사진 폴더에 저장.
