# 끝판왕 (한글 명령어) - mega-audit alias

이 명령어는 `/mega-audit`의 한글 alias입니다. 동작은 완전히 동일합니다.

인자: $ARGUMENTS

---

## 동작

`skills/mega-audit.md`의 모든 로직을 그대로 실행합니다. 인자 파싱, Pre-Flight, 5-Phase 파이프라인, Auto-Fix, Iteration, Report 생성 — 모두 동일.

**즉시 `mega-audit.md`의 절차를 처음부터 끝까지 따라 실행하세요.**

---

## 사용 예시

```bash
/끝판왕                                    # 활성 프로젝트 자동 감지, 기본 설정
/끝판왕 pos-calculator-web                  # 특정 프로젝트
/끝판왕 pos-calculator-web --threshold=90  # 임계값 조정
/끝판왕 auto-shop-manager --only=db,perf   # 특정 영역만
/끝판왕 . --dry-run                        # 현재 폴더, 보고만
/끝판왕 . --mode=fast --max-iter=3         # 빠른 모드, 3회 반복
```

전체 옵션과 동작 명세는 [mega-audit.md](mega-audit.md) 참조.
