# /module-capture — 시리얼 장치 데이터 캡처·역공학 에이전트

USB-시리얼 장치와 전용 PC프로그램의 통신을 가로채 내부 데이터(펌웨어·사운드)를 추출·분석한다.
**검증 사례:** JSR 저스트사운드부스터(차량 가상배기음 모듈) — 사운드를 16비트 PCM WAV로 추출 성공.

## ⚠️ 핵심 노하우 (이거 모르면 막힘 — 실패로 배운 것)

### 캡처 도구
- ✅ **Eltima Serial Port Monitor** 사용 (`winget install Eltima.SerialPortMonitor`).
  - 드라이버 **SPSniff가 WHQL 정식서명** → Win10 서명강제 통과. 14일 무료체험(전기능).
- ❌ **IO Ninja 쓰지 말 것** — 모니터 드라이버(tdevmon)가 **서명 없어서** Win10 x64 + 안랩V3에서 설치 실패.
- com0com choco판도 unsigned라 실패.

### 캡처 절차 (순서 중요!)
1. **Eltima 먼저 모니터링 시작** (New Session → Serial Monitor → COMx → Capture).
   - ⚠️ 평가판은 첫 실행 시 "Evaluate" 눌러 14일 활성화. 모니터링은 GUI 클릭 필요(키 자동입력 금지 — 포커스 튀어 타 앱 건드림).
2. **그 다음** 전용 프로그램(예: PC_Download)을 **재연결**시킴.
   - 이미 포트가 열린 상태론 후킹 안 됨. 모니터 켠 뒤 열려야 잡힘.
3. 대상 동작(사운드 다운로드/플래싱) 실행 → File→Save로 `.spm` 저장.
4. ⚠️ **분석 중 COM 포트를 직접 열지 말 것** — 전용프로그램과 충돌해 "디바이스 못찾음"으로 꺼짐.

### PowerShell 분석 함정 (전부 실제로 당함)
- 🔴 `[byte] -shl 8` = **0으로 잘림**. 16비트 재구성 시 반드시 `([int]$b[$i]) -bor (([int]$b[$i+1]) -shl 8)`.
- 🔴 `List[int]` 인덱서 결과를 `[Math]::Abs()`에 직접 넣으면 박싱오류 → **`.ToArray()`로 int[] 변환** 후 사용.
- 🔴 디클릭(인접평균 보간)을 **큰 진폭 파형에 쓰면 전부 0**(인접 +X/-X 평균=0을 스파이크로 오판). 정규화만 하거나 경계 crossfade만.
- 🔴 `[int]$hash.key*N` 우선순위 함정 → `[int]$hash`가 먼저 적용됨. 중간변수로 분리.
- 🔴 Remove-Item을 큰 스크립트 안에 넣으면 안전훅이 경로 오인 차단 → 삭제는 별도 명령으로.

## 작업 흐름

### 1. 장치 파악
- `Get-PnpDevice -Class Ports` 로 COM포트·VID/PID 확인 (CP210x=VID_10C4&PID_EA60).
- 전용 프로그램 위치·구조 파악 (exe 문자열·폼이름·SFTP 단서 등).
- baud 등 통신속도 확인 (캡처하면 "Open: port COMx at 115200" 식으로 나옴).

### 2. 캡처 (위 노하우대로 Eltima)

### 3. .spm 분석·추출
- `.spm` = Eltima v3 바이너리. "COM4" UTF-16 마커로 IRP 레코드 구분.
- 데이터프레임 찾기: `FA A5`(JSR 동기화 마커) + 길이. 파일헤더 프레임엔 `.wav` 파일명·20바이트 키(체크섬 추정).
- PCM 추출: 마커간 큰갭(>4000) 청크에서 FA A5+헤더 스킵 → 16비트 LE, L=R 스테레오중복(4바이트마다 L채널) → 정렬(0~3 중 L=R중복 최대) 자동검출 → int[]로 모아 WAV.
- 검증: 추출 후 **샘플값 출력**(수천 단위 매끈하면 정상, 0~255면 -shl 버그).

### 4. 산출물 정리
- 폴더: `01_문서`(md+PDF) / `02_추출사운드`(wav) / `03_원본캡처`(spm).
- PDF: md→html(파이썬 변환기)→`msedge --headless --print-to-pdf`. 표지+CSS로 고급화.

## JSR 저스트사운드부스터 — 확정 스펙 (참고)
- 모듈=RPM(CAN으로 읽음) 따라 차종 배기음 재생. PC_Download(DLP)로 플래싱, 폰앱계정 로그인.
- 사운드=무압축 16비트 PCM ~22kHz, L=R, 차종별 .wav(488/911GT3/C63AMG/370Z…), 슬롯 a0~b0.
- 한 파일에 RPM단계(공회전~고RPM~감속팝) 연속(무음경계 없음). 피치=RPM 대용.
- 프로토콜: FA A5 + 헤더(파일명·파라미터) + 20바이트 키 + PCM 8KB청크. JSR서버서 SFTP로 받아 플래싱.
- 자가제작 난이도: 소리만들기🟢 / 포장·서명(20바이트 키)🔴 / 플래셔제작🔴.
- CAN RPM: OBD2 PID `01 0C`가 만능(차종무관). raw CAN은 opendbc(github.com/commaai/opendbc) 참고.
